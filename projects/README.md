**Maturity labels**

- **Featured runnable suite**: safe to show in an interview now.
- **Showcase spec + CI / Tagged suites + CI / Runnable + CI**: working and automated; promote one focused end-to-end scenario and add visual evidence next.
- **Foundation available**: kept as evidence of learning; add a runnable mini project before presenting as a primary project.
- **Learning material**: exercises only; extract a project before claiming the skill.
