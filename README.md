# QA Automation Portfolio

Self-directed QA and software-testing practice, organized by tool and learning purpose.

## Projects

- [`Playwright/`](Playwright/) — registered deterministic browser suites plus unregistered practice examples.
- [`cypress/`](cypress/) — Cypress UI automation exercises.
- [`Robot-Framework/`](Robot-Framework/) — Robot Framework UI and API suites.
- [`Workshops/`](Workshops/) — standalone course and workshop material; each workshop keeps its own dependencies.

Install and run commands belong inside each project directory. The repository root intentionally has no Node package or test runner configuration.
